# Enunciado original — Impresoras

Fuente: `impresoras.pdf` de **Programación de Servicios y Procesos**.

Un centro de cálculo dispone de un número limitado de impresoras de **tipo A** y de **tipo B**, numeradas dentro de cada tipo. Cada operación de impresión dura aproximadamente 3 segundos.

Se consideran tres clases de procesos:

1. procesos que requieren una impresora A;
2. procesos que requieren una impresora B;
3. procesos que pueden utilizar indistintamente una impresora A o B.

Los procesos generan trabajos y deben imprimirlos en una impresora compatible. **Dos procesos no pueden imprimir simultáneamente sobre la misma impresora**. Si no existe en ese momento una impresora compatible libre, el proceso debe esperar hasta que una quede disponible.

No existe una base de datos asociada a este ejercicio.
